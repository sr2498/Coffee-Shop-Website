# Coffee-Shop-Website

Journey Bean Coffee Shop is a responsive web application developed as a group project by a team of four members. The project was designed to create a welcoming, modern, and user-friendly online experience that reflects the cozy, community-focused atmosphere of a coffee shop.

Our team collaborated throughout the development process using Agile methodology and DevOps practices, with GitHub for version control and GitHub Actions for workflow automation.

## Technologies
- HTML5 – Website structure
- Tailwind CSS – Responsive design and styling
- React.js – Reusable and interactive UI components
- Node.js – Backend and development support
- Figma – UI/UX design and prototyping
- Git & GitHub – Version control and team collaboration
- GitHub Actions – Workflow and CI/CD automation
- Mailchimp – Email subscription integration
- Agile Methodology – Team collaboration and iterative development
- DevOps Practices – Development workflow and automation

## Key Features
- Responsive and user-friendly design
- Easy navigation between pages
- Coffee menu and product information
- Blog for events and community updates
- Email subscription using Mailchimp
- Social media integration
- Reusable React components
- Team-based development using Git and GitHub
- GitHub Actions for workflow automation
- Agile and DevOps-based development process

## Homepage
The Homepage welcomes visitors with a large coffee-themed image and an engaging message: “Sign up to get a free drink.”
It provides easy navigation to the main sections of the website, including Menu, Blog, About, and Join. The page also includes social media links for Facebook and Twitter, along with a Sign Up button.

## Menu
The Menu page displays a selection of coffee drinks and flavors available at Journey Bean Coffee Shop. It provides visitors with a simple and convenient way to explore the shop's offerings.

## About
The About page introduces visitors to the history, mission, and values of Journey Bean Coffee Shop.
It highlights the shop's commitment to creating a friendly and welcoming environment where people can enjoy quality coffee and connect with the community.

## Blog
The Blog page features coffee-themed visuals along with posts about coffee, upcoming events, community activities, and shop updates.
This section helps Journey Bean stay connected with its customers and local community.

## Join
The Join page contains a simple email subscription form that allows visitors to sign up for special offers, promotions, events, and coffee shop updates. We integrated Mailchimp to manage email subscriptions and keep customers informed about the latest news and offers.
